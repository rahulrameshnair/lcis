# DLR tool for life cycle inventory schema 

## What is it?
It is a Python tool developed at the German Aerospace Center (DLR) that aids in converting foreground life cycle inventories (LCI) in compliance with the life cycle inventory schema (LCIS). It makes use of the Brightway LCA framework.

## What is LCIS?

LCIS (version 2024) is a simple and intuitive schema proposed for the sharing of life cycle inventories based on existing standards and conventions to promote open-data with minimal technical hurdles. This tool is a python implementation for the conversion of life cycle inventories in compliance with this schema. The detailed structure and background of LCIS is under peer review. (Link will be updated soon). However, a pre-print is soon to be available via arXiv. Please refer to this schema to understand the terminology and usage of this tool.

## Installation & Usage

Install the package directly from GitHub into the Python environment used by
Jupyter:

```bash
pip install git+https://github.com/<owner>/<repo>.git
```

For local development from a checkout:

```bash
pip install -e .
```

The `environment.yml` file is kept as an optional Brightway/Jupyter reference
environment. It is useful when recreating the tested Windows setup, but the
package itself is installed with pip.

### Usage

The supported workflow is the `lcis.inventory` export package. The notebooks in
`Inventory/` are thin examples that import `lcis` and call the package API.

1. Open and run `Inventory/export_lci.ipynb` to generate the LCIS inventory CSV,
   formatted XLSX, and database properties CSV.
2. Generate metadata when you are ready, either from the notebook or from the
   command line with `lcis metadata-wizard`.
3. Open and run `Inventory/network/LCI_network.ipynb` to generate a GraphML
   network file. The resulting network can be rendered in software such as
   Cytoscape or Gephi. A sample stylesheet is provided in
   `Inventory/network/stylesheets/`.
4. Packaged spreadsheet templates are available through `lcis.templates` after
   installation.

The same export functions can be used directly from Python:

```python
from lcis.inventory import export_inventory, export_network, run_metadata_wizard

export_inventory(
    project_name="my-brightway-project",
    database_name="my-foreground-database",
    output_stem="my_dataset",
    schema_version="LCIS2024",
    dataset_version="1.0.0",
    output_dir="exports",
)

export_network(
    project_name="my-brightway-project",
    database_name="my-foreground-database",
    output_path="exports/my-foreground-database.graphml",
)

run_metadata_wizard(
    output_dir="exports",
    dataset_name="my_dataset",
)
```

Metadata can also be collected from the command line:

```bash
lcis metadata-wizard --output-dir exports --dataset-name my_dataset
```

The metadata wizard is driven by the packaged Excel template. It fills a
human-readable workbook and writes matching machine-readable JSON and CSV files.

*Note*: files generated by the notebooks are stored in the selected
`output_dir`, or in the current notebook directory when `.` is used.


The `/Imports` workflow is experimental and is not part of the supported
installable export API yet. It is retained for future cleanup.


## Compatibility

The code has been tested for compatibility with the following versions of Brightway and Python. Due to the rapidly evovling nature of Brightway, these versions have to be kept in mind prior to the utlization of this code.
- Brightway 2.4.2, 2.4.3
  - bw2calc 1.8.1, 1.8.2
  - bw2data 3.6.5, 3.6.6
  - bw2io 0.8.8
  - bw2analyzer 0.10
  - bw_migrations 0.1, 0.2
- Python: 3.9, 3.10
- OS: Win 10 and 11. 

All jupyter notebooks were primarily tested in VSCode, and Spyder using environment.yml. A conventional browser-based jupyternotebook should also work.
